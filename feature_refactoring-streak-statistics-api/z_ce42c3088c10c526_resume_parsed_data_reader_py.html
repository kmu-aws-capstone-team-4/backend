2 

3serializer 의 parsed_data 응답이 "정규화 테이블" 을 soft-source 로 삼도록 한다. 

4Writer 는 JSONField 에도 동일 값을 저장하므로, 정규화가 아직 백필되지 않은 과거 데이터는 

5JSONField fallback 경로를 이용한다. 

6 

7N+1 주의: 

8- 이 reader 는 resume 당 1:1 (basic_info / summary / career_meta) 과 

9 여러 1:N / N:M 관계에 접근한다. 호출 측(`ResumeViewSet.retrieve` 등) 에서 이들을 

10 `select_related` / `prefetch_related` 로 미리 로드하면 reader 는 추가 쿼리를 발생시키지 않는다. 

11- `_has_any_normalized_rows` 같은 exists 게이트는 매 호출마다 12개의 exists 쿼리를 발생시켜 

12 오히려 비용을 키우므로 제거했다. 대신 완성된 dict 의 비어있음을 확인해 fallback 한다. 

13"""

22def _safe_one_to_one(resume: Resume, attr: str): 

23 """reverse 1:1 접근. prefetch/select_related 되어 있으면 추가 쿼리 없이 리턴. 

24 

25 존재하지 않으면 None 반환. RelatedObjectDoesNotExist 는 AttributeError 의 하위 타입이라 

26 try/except 로 잡을 수 있다. 

27 """ 

28 try: 

29 return getattr(resume, attr) 

30 except AttributeError: 

31 return None

56 def _is_nonempty(self, data: dict) -> bool: 

57 """조립된 dict 에 의미 있는 데이터가 하나라도 있는지 검사.""" 

58 if data.get("summary"): 

59 return True 

60 if data.get("total_experience_years") is not None: 

61 return True 

62 if data.get("job_category"): 

63 return True 

64 for key in ( 

65 "experiences", 

66 "educations", 

67 "certifications", 

68 "awards", 

69 "projects", 

70 "languages_spoken", 

71 "industry_domains", 

72 "keywords", 

73 ): 

74 if data.get(key): 

75 return True 

76 basic_info = data.get("basic_info") or {} 

77 if any(basic_info.get(k) for k in ("name", "email", "phone", "location")): 

78 return True 

79 skills = data.get("skills") or {} 

80 if any(skills.get(k) for k in ("technical", "soft", "tools", "languages")):
